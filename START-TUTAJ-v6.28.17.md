# CRPE Home v6.28.17

Skrócono karty odbiorców. Wspólny wiersz tekstowy dopasowuje się do najdłuższego opisu zamiast wymuszać dużą pustą przestrzeń. Grafiki pozostają jednakowe i wyrównane. W sprawdzonym widoku desktop karty mają po 275 px, a przy 390 px po 265 px; brak poziomego przewijania.

Build produkcyjny i 21 kontroli wydania poprawne. Sprawdzono wygląd w przeglądarce. Zmiana obejmuje CSS Home; backend i baza bez zmian.

Rozpakuj ZIP i skopiuj zawartość folderu cpd-app-main do lokalnego repo, zastępując pliki. Zachowaj .git i pliki środowiska. Następnie commit i push. SQL nie jest potrzebny.
