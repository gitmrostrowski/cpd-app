# CRPE Home v6.28.20

Karty odbiorców mają ikonę obok nazwy i krótki opis na pełnej szerokości poniżej. Strzałka jest w prawym dolnym rogu, bez osobnego wiersza. Grafiki zachowały rozmiar. W sprawdzonym widoku desktop każda karta ma około 195 x 204 px, wcześniej wysokość wynosiła około 275 px. Na telefonie 390 px karty mają równą wysokość 239 px, bez poziomego przewijania.

Build produkcyjny i 22 kontrole wydania poprawne. Sprawdzono wygląd w przeglądarce. Zmiany względem v6.28.19 dotyczą wyłącznie Home: CSS i trzech krótkich opisów. Backend i baza bez zmian. SQL nie jest potrzebny.

Rozpakuj paczkę i skopiuj zawartość cpd-app-main do lokalnego repo, zastępując pliki. Zachowaj .git i własne pliki środowiska. Następnie commit i push.
