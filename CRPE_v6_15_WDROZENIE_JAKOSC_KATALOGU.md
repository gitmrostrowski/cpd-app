# Wdrożenie CRPE v6.15

Ta wersja nie wymaga uruchamiania SQL-a.

1. Podmień zawartość repozytorium zawartością katalogu `cpd-app-main`.
2. Zachowaj aktualne zmienne środowiskowe Vercel dla Supabase i `NEXT_PUBLIC_SITE_URL`.
3. Wdróż standardowo przez GitHub / Vercel.
4. Po wdrożeniu sprawdź `/baza-szkolen`, jeden adres szczegółów, `/sitemap.xml` i `/robots.txt`.

Skalowanie zapytań PostgreSQL jest zaplanowane jako osobny etap i będzie wymagało SQL-a.
