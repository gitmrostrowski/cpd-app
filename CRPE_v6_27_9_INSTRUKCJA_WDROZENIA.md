# CRPE v6.27.9 — instrukcja wdrożenia

1. Utwórz branch z aktualnego `main`, np. `feature/home-status-polish-v6.27.9`.
2. Skopiuj zawartość paczki v6.27.9 do katalogu repozytorium.
3. Sprawdź zmiany w GitHub Desktop.
4. Uruchom `npm run check:v6.27.9` oraz `npm run check:v6.27.8`.
5. Commit: `CRPE v6.27.9 - dopracowanie hero i kompaktowy status CPD`.
6. Opublikuj branch i sprawdź Vercel Preview.
7. Na Preview sprawdź trzy role w hero oraz oba widoki `Przebieg` / `Przegląd` w Panelu CPD.

Nie wymaga SQL, zmian Supabase, sekretów ani nowych zmiennych Vercel.
