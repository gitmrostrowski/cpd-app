# CRPE v6.27.10 — instrukcja wdrożenia

1. Utwórz branch z aktualnego `main`, np. `feature/role-switcher-polish-v6.27.10`.
2. Skopiuj zawartość paczki v6.27.10 do katalogu repozytorium.
3. Sprawdź listę zmian przed commitem.
4. Commit: `CRPE v6.27.10 - polish przełącznika ról na Home`.
5. Opublikuj branch i sprawdź Vercel Preview na szerokości desktop oraz mobile.
6. Przełącz kolejno Medyk → Placówka → Organizator. Zmiana roli ma być czytelna, ale control nie powinien zmieniać optycznej masy ani wyglądać jak trzy różne style przycisków.

SQL / Supabase / sekrety: bez zmian.
