# CRPE v6.28.13

Zmiana względem v6.28.12 obejmuje wyłącznie wygląd strony głównej:
- Na desktopie prawa karta jest przesunięta o 36 px w dół, do początku nagłówka. Zmniejszono minimalną wysokość jej zawartości o 36 px, aby ograniczyć przesunięcie dolnej krawędzi.
- Usunięto dekoracyjną krzywą z luźnymi turkusowymi kropkami w sekcji „CRPE w praktyce”.
- Zachowano treści, trzy role, domyślny wybór placówki i mobilną kolejność elementów.

Sprawdzenie: kompilacja produkcyjna i 25 kontroli wydania zakończone poprawnie. Nie testowano operacji na produkcyjnej bazie. SQL nie jest potrzebny.

Rozpakuj ZIP. Skopiuj ZAWARTOŚĆ folderu cpd-app-main do lokalnego repo wskazanego przez GitHub Desktop, zastępując pliki. Zachowaj .git i własne pliki środowiska. Następnie sprawdź zmiany, wykonaj commit i push. Przed publikacją obejrzyj podgląd wdrożenia.

Ta instrukcja jest aktualna; wcześniejsze START-TUTAJ opisują historię zmian.
