# CRPE Home v6.28.16

Poprawiono grafiki w kartach „Wybierz, kim jesteś”. Każda karta ma osobny, równy wiersz na opis, grafikę oraz strzałkę. Usunięto wymuszenie kwadratowych proporcji karty, które pomniejszało ilustracje zależnie od długości opisu. Grafiki mają 140 px wysokości na desktopie i 160 px na małym ekranie; zachowują proporcje i nie są przycinane. Efekt uniesienia karty po najechaniu pozostaje.

Build produkcyjny i 21 kontroli wydania przeszły poprawnie. Sprawdzono wizualnie trzy grafiki w przeglądarce i potwierdzono jednakową wysokość 140 px. Zmiana dotyczy CSS Home; backend i baza bez zmian.

Rozpakuj ZIP i skopiuj zawartość cpd-app-main do lokalnego repo, zastępując pliki. Zachowaj .git oraz pliki środowiska. Następnie commit i push w GitHub Desktop. SQL nie jest potrzebny.
